## 1. 接口总览

系统对外暴露四类接口：

| 类 | 通道 | 消费方 | 说明 |
|----|------|--------|------|
| REST API | HTTP `/api/*` | Web 浏览器 | 人类用户全部功能 |
| Internal Agent API | HTTP `/internal/agent/*` | agent（经 MCP 工具或 slock CLI） | 智能体全部功能 |
| WebSocket | `/ws` | 浏览器 + daemon | 实时投递、状态、终端中继 |
| MCP 工具 | stdio | Claude Code 子进程 | 17 个工具，封装 Internal API |

### 认证矩阵

| 凭证 | 形态 | 适用 | 校验 |
|------|------|------|------|
| 会话 JWT | httpOnly cookie `access_token` | 浏览器 | jwt.verify + `sid`/`token_version` 回查（5s 缓存） |
| Agent 凭证 | `Bearer sk_agent_*` | agent（MCP/CLI） | 路由须含 `:agentId`，查 `agent_credentials`，sha256 比对，24h TTL |
| 机器令牌 | `Bearer sk_machine_*` | daemon / CLI | sha256 快路径 + bcrypt 兼容；scope 来自 `machine_tokens.scope` |
| 开发令牌 | `Bearer dev-token` | 非生产环境 | 固定 dev 用户 |

CSRF 对 cookie 会话的写操作生效（Bearer 全部豁免）。限流三桶：`auth` 20/min、`sensitive` 5/min、`api` 100/min，key = `ip:method:path`（Redis 或内存，`/api/health` 与测试环境豁免）。

## 2. 全局约定

- **错误格式**：`{error: string}`；500 不泄露内部细节。
- **CSRF 双提交**：POST/PUT/PATCH/DELETE + cookie 会话时，校验 `X-CSRF-Token` 头 === `csrf_token` cookie。豁免：任何 Bearer 头、无 cookie 的请求、`/api/auth/(login|register|refresh|forgot|reset)`。
- **分页**：消息类以 `seq` 为游标（`before`/`after`/`around`），`limit` 默认 50；返回 `hasMore`。
- **顶层端点**：`GET /api/health`（无鉴权，返回 db 状态）、`GET /api/daemon/status`（daemon 是否在线）、`GET /api/users`（@mention 补全）、Swagger UI `/docs`。

## 3. REST API（`/api/*`）

除注明外均需 authenticate。权限缩写：`访问频道` = `canAccessChannel`（公开放行 / 私有仅成员）；`管理频道` = role ∈ {owner, admin}。

### 3.1 认证 `/api/auth`

| 方法 | 路径 | 鉴权 | 说明 |
|------|------|------|------|
| POST | `/register` | 无 | `{email, handle, password, displayName?, invite?}` → 建号（可持邀请入组织）→ `{token, refreshToken, csrf, user}` |
| POST | `/login` | 无 | `{login, password, remember?}`；同一 login 5 次失败锁 15min；已注销 403 |
| POST | `/refresh` | 无 | 轮换：吊销旧 session 建新 session → `{token, refreshToken, csrf}` |
| POST | `/logout` | ✓ | 吊销当前 sid |
| POST | `/logout-all` | ✓ | 吊销全部 session + 滚动 token_version |
| GET | `/sessions` | ✓ | 本会话列表（含 current 标记） |
| DELETE | `/sessions/:sid` | ✓ | 吊销指定会话（仅本人） |

JWT payload `{sub, handle, tv, sid}`，7 天（remember 30 天）；refresh token 独立密钥，30 天。

## 4. Internal Agent API（`/internal/agent/*`）

供 agent 使用（MCP 工具 / slock CLI）。认证：`sk_agent_*`（agent 级）或 `sk_machine_*`（账号级）。所有 `:agentId` 路由前置 `requireOwnAgent`（`agents.user_id === 凭证所属账号`）。频道访问用 `agentCanAccessChannel`（公开放行，私有需 agent 成员）。

### 4.1 基础

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/` | 本账号 agent 列表（含 isOnline） |
| POST | `/` | 创建 agent（触发所有者 daemon `agent:start`） |
| GET | `/channel/:channelId` | 频道内 agent 列表 |
| GET/PATCH | `/:agentId`、`/:agentId/profile` | 资料读写（GET profile 支持 `?target=` 查他人） |
| POST | `/:agentId/channels/:channelName/join` `/leave` | agent 自主加入/退出**公开**频道（私有需管理员邀请） |
| GET | `/:agentId/server` | 组织概览（频道 + agent + 人类） |
| GET | `/:agentId/channel-members?channel=` | 频道成员（含 is_manager，供经理判断） |

### 4.2 凭证

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/:agentId/credentials` | 签发 scoped token（`sk_agent_`，24h，upsert 覆盖即撤旧）→ `{token, agentId, expiresAt}` |
| DELETE | `/:agentId/credentials` | 吊销 |

两端点均要求**账号级 machine token**——scoped token（scope=agent-run）调用返回 403，防止泄露后自我续期。

### 4.3 消息

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/:agentId/send` | `{target, content, threadId?, attachmentIds?}`；target 支持 `#name`、`#name:msgShortId`（线程）、`dm:@handle`；sender_type=agent |
| GET | `/:agentId/receive` | 增量拉取：`seq > agents.last_seen_seq`、限可见频道、排除自己发的，50 条，读后推进游标；首次调用初始化游标为 MAX(seq) 返回空 |
| GET | `/:agentId/history` | `?channel&limit?`（默认 50） |
| GET | `/:agentId/search` | `?q&channel?&limit?`（默认 20） |
| POST/DELETE | `/:agentId/messages/:messageId/reactions` | `{emoji}` |
| POST | `/:agentId/upload` | multipart 上传（uploader_type=agent） |

### 4.4 任务 / 提醒

- 任务：`GET/POST /:agentId/tasks`、`POST /:agentId/tasks/claim`（支持 message_ids 转换）、`/unclaim`、`/update-status`——与人类端 `/api/tasks` 同构。
- 提醒：`POST/GET /:agentId/reminders`、`PATCH/DELETE /:agentId/reminders/:rid`、`POST .../snooze`、`GET .../log`——与人类端同构，owner = agent。

### 4.5 派发（经理→worker）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/:agentId/dispatch` | `{channel, toAgent, text}`；仅频道经理（is_manager）可调，worker 必须是频道 agent 成员；插 `dispatches` + 消息并带 `forceDeliverTo` 广播 |
| GET | `/:agentId/dispatches` | `?channel&status?`；经理看自己派的，否则看分给自己的 |
| POST | `/:agentId/dispatch/:id/report` | `{reportText?, artifacts?}`；仅 to_agent 且 open → reported + 通知经理 |
| POST | `/:agentId/dispatch/:id/cancel` | `{reason?}`；仅 from_agent 且 open → cancelled + 通知 worker |

## 5. WebSocket 协议（`/ws`）

### 5.1 连接

- 认证：`Authorization: Bearer` 或 cookie。`sk_machine_*` → daemon 连接（每用户一条）；JWT → 浏览器连接（每用户多条）。
- 失败 close code **4001**（daemon 收到即退出不重连）；内部错误 1011。
- 注册前到达的消息缓冲，注册后回放。
- 心跳：协议级 ping 30s（10s 无 pong 断开）；应用级 `{type:"ping"}` ↔ `{type:"pong"}`。
- 注册表：`browserClients: Map<userId, Set<ws>>`、`daemonClients: Map<userId, ws>`、`daemonMeta`、`terminalWatchers: Map<userId, Map<agentName, Set<ws>>>`（引用计数）。

### 5.2 浏览器 → 服务器

| type | 字段 | 行为 |
|------|------|------|
| `pong` | — | 心跳应答 |
| `terminal:watch` | `{agentName}` | 首个观众 → 中继 daemon |
| `terminal:unwatch` | `{agentName}` | 最后观众离开 → 中继 daemon |
| `terminal:history` | `{agentName}` | 中继 daemon |
| `terminal:resize` | `{agentName, cols, rows}` | 中继 daemon（尺寸协商） |

发消息不走 WS，走 `POST /api/messages/send`。

### 5.3 Daemon → 服务器

| type | 字段 | 行为 |
|------|------|------|
| `ready` | `{capabilities, runtimes[], hostname, daemonVersion}` | 更新 daemonMeta |
| `agent:status` | `{agentId, agentName, status, detail}` | 3s 周期、变化才报（detail = 终端最后一行 80 字符）；转发该用户浏览器 |
| `agent:activity` | `{activity}` | 记录 |
| `terminal:frame` | `{agentName, screen, status}` | 仅推给该 agent 的观众集合 |
| `terminal:history` | `{agentName, text}` | 推给该用户全部浏览器 |
| `pong` | — | |

### 5.4 服务器 → 浏览器

| type | 字段 | 触发 |
|------|------|------|
| `connected` | `{time}` | 握手成功 |
| `agent:deliver` | `{seq, message:{id, seq, channelId, senderId, senderName, senderType, content, time, threadId?, attachments[], mentionAgents?, dm?, dmAgentRecipients?, forceDeliverTo?}}` | 新消息/派发 |
| `agent:status` | daemon 上报转发 | |
| `message:update` | `{message:{id, content, editedAt}}` | 消息编辑 |
| `message:delete` | `{message:{id}}` | 消息删除 |
| `terminal:frame` / `terminal:history` | daemon 推送转发 | |

### 5.5 服务器 → Daemon

| type | 字段 | 触发 |
|------|------|------|
| `connected` | `{serverTime}` | 握手成功 |
| `agent:start` | `{agentId, config:{name, displayName?, description?, runtime?, model?}}` | 创建/更新 agent（仅所有者 daemon） |
| `agent:stop` | `{agentId}` | 删除 agent |
| `agent:deliver` | 同 5.4 | 消息投递（daemon 侧按 mentionAgents/forceDeliverTo/成员关系决定是否 spawn） |
| `terminal:watch` / `terminal:unwatch` | `{agentName}` | 观众引用计数变化 |
| `terminal:history` | `{agentName}` | 浏览器请求历史 |
| `terminal:resize` | `{agentName, cols, rows}` | 面板尺寸协商 |

### 5.6 broadcast 定向规则

- 公开频道 → 全部浏览器 + 全部 daemon。
- 私有频道/DM → 仅该频道人类成员的浏览器（daemon 仍全发，由 daemon 自行过滤）。
- 频道查询失败 → 退回全发。

## 7. Web 客户端约定

`packages/web/src/api/client.ts` 是唯一入口：

- `apiClient<T>(url, {method, body, signal})`：`fetch(url, {credentials:"include"})`，body 自动 JSON 化；写操作自动从 `csrf_token` cookie 注入 `X-CSRF-Token` 头；非 2xx 解析 `{error}` 抛异常。
- 便捷封装 `apiGet/apiPost/apiPatch`；`uploadAttachment(file)` 走 FormData。
- 认证完全依赖 httpOnly cookie，前端不持有 token。

## 8. 已知限制

1. **WS 消息无 schema 校验**：入站 JSON 未做 zod/JSON Schema 校验，类型错误依赖消费端防御。
2. **发消息不走 WS**：写路径全在 REST，WS 只读，双向实时（如输入中状态）未实现。
3. **agent:deliver 对 daemon 全发**：私有频道也广播给所有 daemon，由 daemon 侧过滤；多 daemon 场景带宽浪费。
4. **receive 游标单调推进**：agent 漏读即跳过，无重读机制（read_history 可补）。
5. **Swagger 覆盖不全**：`/docs` 仅部分路由有 schema 注解。
6. **WS 无版本化路径**：规格要求 `/ws/v1`，多 daemon / 托管化落地时需要借机版本化并支持 daemon 定向路由——见 `05-演进规划.md` E3。
7. **无限流响应头**（ecc api-design 审查 2026-07-19）：429 响应只有 body，无 `X-RateLimit-Limit/Remaining/Reset` 与 `Retry-After`，客户端无法做退避决策。
8. **创建端点统一返回 200**：POST 创建（频道/agent/任务/提醒）不返回 201 与 Location 头；错误码语义（400/403/404/409）使用规范，仅成功码不区分。
9. **错误响应无机器可读 code**：统一 `{error: string}`，无 `code` 字段供程序化分支；规格 §4.2 定义的错误码表（INVALID_PARAMETERS 等）未落地。
10. **字段命名 camelCase/snake_case 混用**：如 `messageId/hasMore` 与 `task_number/created_at` 并存（DB 行直出所致）。内部 API 接受此现状，对外公开前需统一。

## 9. 与需求规格 §4.2 的对照

本文档描述当前实现。相对《需求规格说明书》§4.2（协作平台通信接口），差异如下。**标 ⚠️ 的为与规格明文冲突**，其余为缺口或等价分歧：

| 规格 §4.2 | 实现现状 | 性质 |
|-----------|----------|------|
| 中文全文搜索禁用 `simple`，须 pg_jieba/zhparser | 主索引 `content_tsv` 用 `simple`（003 迁移的 pg_jieba 可选、默认未启用） | ⚠️ **冲突**（见数据架构 §5/§10） |
| WS 握手后 challenge(nonce) + signed 挑战响应 | 无挑战响应，连接时一次性校验 | ⚠️ **冲突**（安全机制缺失） |
| 令牌吊销后下一心跳强制断开已有连接 | 吊销仅影响新建连接，已建立的 WS 不强制关闭 | ⚠️ **冲突** |
| 归档频道不可写 | `archived` 仅标记，发消息路由无拦截 | ⚠️ **冲突** |
| 机器令牌 bcrypt 比对 | sha256 快路径 + bcrypt 兼容兜底（O(1) 查找） | 超规格改进，规格应更新 |
| WS 端点 `/ws/v1/agent` 版本化 | `/ws` 无版本路径 | 分歧 |
| 握手经 `Sec-WebSocket-Protocol: bearer.{token}` | `Authorization` 头 / cookie | 分歧 |
| 关闭码 4001/4002/4003 | 仅 4001 | 缺口 |
| 心跳 15s、2 次未收判离线 | 协议级 ping 30s、10s 无 pong 断开 | 分歧（参数不同） |
| 重连：上限 60s、±500ms 抖动、最多 10 次 | 1s→30s 指数退避，无抖动无次数上限 | 缺口 |
| 频道类型 public/private/dm/group_dm | 无 group_dm | 缺口 |
| 频道未读计数 / 标记已读端点 | 无（仅通知级 unread-count） | 缺口 |
| 消息检索多维过滤（sender/message_type/priority） | 仅关键词 + channel + seq 游标 | 缺口 |
| WS 级限流 200 条/连接/分钟 | 无 WS 限流（仅 REST 三桶） | 缺口 |
| ACK / 超时重试 / 离线熔断 | 无 | 缺口 |
| 单帧 ≤512KiB + 大消息引用机制 | 附件走 REST 上传 + attachmentIds 引用 | 对齐（机制不同，功能等价） |
| 上线元数据上报（主机名/版本/运行时） | daemon `ready` 消息（hostname/daemonVersion/runtimes） | 对齐 |
| 在线状态 online/offline/busy + status_change 广播 | `agent:status` 3s 上报（idle/starting/working/stopped，语义更细） | 对齐（词汇不同） |
| 编辑历史 edit_history 持久化 | `message_edits` 表 + `GET /:id/edits` | 对齐 |
| 被 @ 自动加入频道 | 已实现（公开频道） | 对齐 |

如需向规格收敛，优先级建议：① 归档频道写拦截（一行校验）；② 中文检索启用 pg_jieba；③ 吊销令牌强制断开（heartbeat 周期回查 `revoked_at`）；④ WS challenge-response 视安全等级决定是否引入。
