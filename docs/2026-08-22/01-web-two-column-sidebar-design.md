# Web 侧栏两列化设计（可折叠 rail + 详情栏）

> 日期：2026-08-22
> 状态：P0+P1 已落地（2026-08-22）；2026-08-23 起 rail 图标进入独立主区页。**搜索 / 动态 / 成员取消 240px 二级栏**（只留 rail + 全页）；聊天 / 任务 / 计算机仍有 pane。
> 范围：`packages/web` 桌面布局；移动端只做映射，不另做一套信息架构
> 依据：当前 `Sidebar.vue` / `AppLayout.vue` / `MobileTabBar.vue` / 路由表

审查通过后再拆实施步骤。本文只定信息架构、交互、路由与分期，不写代码。

---

## 0. 一句话

把现在的 **单列 240px 清单侧栏** 拆成 Discord / Slack 式两列：

1. **图标轨（rail）** 常驻、窄、不可关；
2. **详情栏（pane）** 可折叠，内容随 rail 选中项切换。

聊天（频道 + 私信）仍是默认工作面；搜索 / 动态 / 任务 / 成员从「塞进同一列的链接」升级为「一级入口」。

│  👥 成员 │                │                                │
│         │                │                                │

```

折叠后：

```
┌─ 56px ─┬────────────────────── 主区 ──────────────────────┐

宽度建议（Tailwind）：

| 列 | 展开 | 折叠 |
|----|------|------|

| 合计占用 | 296px | 56px |

过渡：`width` 200ms ease。折叠时 pane 内焦点还回主区，不留不可见 tab stop。

## 4. 五个 pane 里放什么

### 4.1 搜索 `search`

把已有 `SearchBar.vue` 从「顶栏下拉」改成 **pane 内完整检索面**（组件可抽 `SearchPane.vue`，复用 `/api/messages/search`）。

```
搜索
┌─────────────────────┐
│ 🔍 搜索消息、人、频道 │
│                     │
│ 最近：#代码项目      │
│       @bugkiller     │
│                     │
│ 结果                 │
│  #产品周会 · 3分钟前 │
│  「……命中摘要……」   │
└─────────────────────┘
```

规则：

- 输入即搜（沿用 300ms debounce）；Esc 清空并关结果，**不强制关 pane**。
- 点结果 → 跳 `/channels/:name#msgId`（现逻辑）；**rail 切到 `chat`，pane 展开聊天列表并高亮该频道**。
- 本期范围：**只搜消息**（API 已有）。频道名 / 成员 handle 的本地过滤作为加分，不挡一期。
- 快捷键：`Ctrl/⌘ + K` 聚焦搜索（打开 pane + 选中 `search`）。`/` 在聊天输入框时仍归 composer，不抢。

顶栏 **不再放搜索框**（省横向空间给频道标题和 `AgentProgressBar`）。

### 4.2 聊天 `chat`（默认）

把当前 `Sidebar.vue` 的频道 / 私有 / 私信三段 **原样搬进 pane**，信息架构不变：

```
聊天                          [+]
┌─────────────────────┐
│ 频道                 │
│  # general           │
│  # 产品讨论          │
│  # 产品周会      2   │
│  # 代码项目          │
│ 私有频道             │
│  🔒 product          │
│  🔒 智慧城市产品周会 │
│ 私信            [+]  │
│  👤 alice            │
│  🤖 my-agent         │
└─────────────────────┘
```

`[+]`：创建频道（现 `CreateChannelModal`）；私信 `[+]`：现 people picker。

未读：沿用 `channelStore.unreadCounts`；rail 聊天图标角标 = 各频道未读之和（不含已打开的当前频道，与现在侧栏数字一致）。

Agent 状态条：从「侧栏最底一条」改为 **聊天 pane 底**（只在看聊天时有意义；任务/成员 pane 不必占高）。连接状态点并入用户头像环，不再单独占一行。

### 4.3 动态 `activity`

把顶栏 `NotificationBell` 下拉 **升级为 pane 列表**（数据仍走 `notificationStore` + `/api/notifications`）。

```
动态                    全部已读
┌─────────────────────┐
│ 筛选：全部 / 未读    │
│                     │
│ 💬 @你 在 #产品周会  │
│    3 分钟前          │
│ ✅ 任务指派 #12      │
│ 📨 来自 @alice      │
│ ⏰ 提醒到期          │
└─────────────────────┘
```

规则：

- 点一条：标记已读 + 跳到频道/DM（现 `handleClick`）；rail 切 `chat`。
- 顶栏 **去掉铃铛**，避免和 rail 动态双入口。未读只出现在 rail 角标。
- 本期不做独立 `/activity` 路由（pane 是视图状态，主区仍显示用户离开前的页面）。若审查认为「刷新必须停在动态」，再加 `/activity`（见 §8 Q2）。
- 筛选「全部 / 未读」一期做；按类型过滤二期。

类型沿用现有：`@mention` / `task_assigned` / `dm` / `reminder`。T4 观察进度 **不进动态**（已有顶栏 `AgentProgressBar` + 频道 ⏳）。

### 4.4 任务 `tasks`

任务看板是 **整页**（四列 Kanban），不适合同步塞进 240px。分工：

| 区域 | 内容 |
|------|------|
| pane | 频道切换 + 该频道任务摘要（待办 / 进行中计数）+ 「在看板中打开」 |
| 主区 | 现有 `TaskBoard.vue`（`/tasks` 或 `/tasks/:channelName`） |

```
任务
┌─────────────────────┐
│ 当前：#代码项目  ▾  │
│ 待办 3 · 进行中 1   │
│                     │
│ # general           │
│ # 产品周会          │
│ # 代码项目      ←   │
└─────────────────────┘
```

点 pane 里的频道 → `router.push('/tasks/' + name)`，主区看板切频道（现 `TaskBoard` 已吃路由参数）。

**不把 Kanban 缩进 pane。** 空频道仍进 `/tasks`，沿用现「按当前频道或第一个频道」逻辑。

### 4.5 成员 `people`（2026-08-23：取消二级栏）

与搜索 / 动态相同：**rail 点成员 → `/people` 全页，不占 240px pane。**

名单、搜索、档案都在主区目录页（见 `docs/2026-08-23/03-member-page-raft-gap-report.md`）。频道级成员管理仍留在 ChannelView 右侧抽屉。Admin 深链在 `/people` 顶栏「管理」菜单。

### 4.6 计算机 `computers`（2026-08-23）

P0 只列「我的」一台。pane 一行：绿/灰点 + 名称；空态 CTA「连接我的计算机」。点行进 `/computers`。不列同事的机。

```
计算机
┌─────────────────────┐
│ ● 灵耀14air   在线  │
└─────────────────────┘
```

## 6. 交互细则

### 6.1 折叠

- pane 展开/折叠是 **视图状态**，不是路由。
- 点 **当前已选** 的产品图标 → 折叠 pane。
- 点 **另一个** 产品图标 → 展开（若已关）并换内容。
- 聊天折叠 **不** `router.push` 离开当前 `#channel` / DM。
- 持久化：`localStorage.slock.sidebar = { pane: 'chat'|'search'|…, open: true|false }`。刷新恢复。非法值回退 `{ pane: 'chat', open: true }`。
- 主区增加「展开侧栏」按钮？**不需要**——rail 还在，再点图标即可。窄桌面（`lg` 以下见 §7）另说。

### 6.2 与路由的同步

| 路由 | rail 选中 | pane 默认 |
|------|-----------|-----------|
| `/channels/*`、`/dm/*` | `chat` | 展开聊天（若用户刚手动关了，尊重 localStorage，**不强制展开**） |
| `/tasks`、`/tasks/:ch` | `tasks` | 展开任务 |
| `/activity` | `activity` | 展开动态 |
| `/people` | `people` | 无二级栏（与搜索/动态相同） |
| `/search` | `search` | 展开搜索 |
| `/admin`、`/admin/channels`、`/admin/metrics` | 无产品高亮；齿轮不亮 | pane 保持上次或关 |
| `/settings/*` | 齿轮视觉选中 | pane 保持上次或关 |
| `/connect` | `people`（接入是成员能力） | 展开成员 |

反向：在聊天 pane 点频道 → 仍 `push /channels/:name`。在任务 pane 点频道 → `push /tasks/:name`。

### 6.3 键盘

| 键 | 行为 |
|----|------|
| `Ctrl/⌘ + K` | 打开搜索 pane 并聚焦输入 |
| `Esc` | 搜索有内容则清空；否则若焦点在 pane 则折叠 pane |
| `Ctrl/⌘ + B` | 切换 pane 开/关（不改选中项） |
| `Alt + 1..5` | 切 search / chat / activity / tasks / people（可选，一期能做就做） |

### 6.4 顶栏精简后

```
[ #代码项目 🔒 ]     [@coder 正在读文件…]     [头像]
```

标题逻辑沿用 `AppLayout.useRouteTitle`。通知铃删除后，顶栏右侧只留头像（设置仍可从这进，与 rail 头像重复——**建议顶栏头像也删，只留 rail**，减少双入口。若审查想留顶栏头像作「设置捷径」，也可以，但不要再挂铃铛）。

`AgentProgressBar` 仍在顶栏中段（T4 已定），不进 rail。

## 8. 请拍板的问题（带推荐）

审查时优先盯这些。没标的按推荐做。

**Q1. 点任务图标时，主区是否强制跳到 `/tasks`？**  
- A（推荐）：是。任务的主工作面是看板，pane 只是频道目录。  
- B：否。只开 pane，主区留在当前聊天（「先瞄一眼计数再决定进不进看板」）。

**Q2. 动态要不要独立路由 `/activity`？**  
- A（推荐）：不要。动态是面板，点条目才进聊天。刷新停在离开前的频道。  
- B：要。刷新/分享停留在动态，浏览器返回键更自然。

**Q3. 顶栏头像还留吗？**  
- A（推荐）：删，只留 rail 底头像，顶栏给进度条。  
- B：留，与 rail 头像同样单菜单。

**Q4. 成员 pane 点 Agent 做什么？**  
- A（推荐）：打开现有终端观察（`uiStore.openTerminal`），与频道里「观察」一致。  
- B：跳 `/admin/agents`。  
- C：仅高亮，无动作（动作走底链「管理 Agent」）。

**Q5. 管理后台 metrics / 频道管理放哪？**  
- A（推荐）：只放用户菜单「管理后台」，进现 `/admin` 概览。成员 pane 只深链 agents + members。  
- B：rail 再加第六个「管理」图标（入口变挤，不建议）。

**Q6. 折叠态要不要把未读角标做成「必须展开才读」？**  
- A（推荐）：rail 图标始终有角标；折叠也能看到有没有事。  
- （无 B，不建议藏未读。）

**Q7. 聊天 pane 里公开/私有还要分段吗？**  
- A（推荐）：保持现状两段，私有带锁。用户已经熟悉。  
- B：合成一段，锁图标区分（更短，少一次滚动）。

- 聊天 pane = 现侧栏频道/DM（零能力回归）
- 其余四键先做「占位 pane + 跳现有路由」（搜索仍可临时用顶栏，动态仍可用铃铛）直到 P1 接上
- 去重：侧栏「接入 Agent」只留一处（用户菜单）

**P1 — 五个 pane 填满**

- SearchPane 替换顶栏缺位搜索；⌘K
- ActivityPane 替换铃铛
- TasksPane 频道目录
- PeoplePane 列表 + 深链
- 顶栏精简；AgentStatusBar 迁聊天 pane 底

**P2 — 移动底栏对齐 + 抛光**

- 底栏四键映射
- 角标、键盘、空态、骨架屏
- 头像 WS 环

P0 单独可合并；P1 是用户能感知的完整形态。

## 12. 验收（审查通过后的完成定义）

桌面：

1. 默认进入 `#general`（或上次频道），rail 高亮聊天，pane 展开，列表与现在一致（公开/私有/私信、未读、创建）。
2. 点动态：铃铛从顶栏消失，pane 列出通知，未读角标在 rail；点条目进频道。
3. 点搜索：pane 内可搜消息并跳转；⌘K 等效。
4. 点任务：pane 出频道目录，主区看板可用。
5. 点成员：能看到 Agent 在线与人名；能进管理页 / 开 DM / 接入向导。
6. 再点当前图标或 ⌘B：pane 关掉，主区变宽，当前频道不丢。
7. 刷新后 pane 开关与选中项恢复。
8. 「接入 Agent」不再出现两遍。

移动：底栏能进聊天抽屉、动态、任务、成员；不出现桌面 rail。
