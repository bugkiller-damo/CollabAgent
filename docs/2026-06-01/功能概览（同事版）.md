# CollabAgent 功能概览（同事版）

> 一句话：CollabAgent 是一个**人和 AI Agent 一起协作的团队聊天平台**——像企业微信/Slack，但里面的「AI 同事」能真正干活：收发消息、领任务、定提醒、传文件、记住事情。
> 更新时间：2026-06-01。（取代 2026-05-30 版）

---

## 这个产品能做什么

### 像普通团队聊天一样
- 多频道聊天，支持**公开频道**和**私有频道**（私有的只有成员能看）。
- **线程回复**：对某条消息展开讨论，不刷屏。
- **@提及**：输入 @ 自动弹出人/AI 列表（支持中文名）。
- 消息支持 **Markdown 富文本 + 代码高亮**、**发图片/文件**（图片可点开大图，文件可下载）、**编辑已发消息**、**链接自动预览**。
- 消息可加 👍 等表情、可复制、可回复。
- **私信（DM）**：人和人、人和 AI、AI 和 AI 都能一对一私聊；私信 AI 不用 @，它会直接回。

### AI Agent 是“真同事”，不只是问答机器人
被 @（或收到私信）后它会：
- **看懂上下文并回复**（在主频道或线程里）。
- **领任务、改状态**：在任务看板里认领、推进到「审查中/完成」。
- **记得住事情**：每个 Agent 有自己的“记忆”，跨对话记住你的偏好、频道在聊什么、长期事项——不会每次从零开始。
- **会定提醒、主动跟进**：比如让它「2 小时后看看那个事办好没」，到点它会自己回来处理。
- **能传文件**：需要时上传并发出文件/截图。
- **进私有频道**：你在频道里 @ 它，它就自动加入这个频道。

### 🆕 接入和管理一键化（2026-06-01 新增）
- **🔌 一键接入向导**（侧栏「接入 Agent」）：注册后跟着三步走——生成命令、在自己电脑跑一行命令连上本机 AI、创建 Agent——页面会自动检测「已上线」，全程不用配置。
- **👥 邀请同事**：管理后台「成员管理」里生成**邀请链接**，发给同事，他点开注册就自动加入你们的协作空间，还能设成员/管理员角色。
- **🛠️ 管理后台**：频道管理（建/归档/删）、成员管理、Agent 管理、**运行指标**（谁在线、消息量、资源占用，实时动画展示）一站搞定。
- **首次登录引导**：右下角小清单带你完成「连 AI → 建 Agent → 邀同事」。

### 用起来顺手
- 浅色 / 深色主题随手切换。
- 网络断了有提示，消息发失败能一键重发，断网时排队、恢复后自动补发。
- 消息很多也不卡（长列表做了优化）。
- 注册有**密码强度提示**，登录有**防爆破保护**（连续失败会锁一会儿）；可设头像；登录设备可远程下线；账户可导出/注销。

## 目前的完成度

✅ **已经能用**（核心功能齐全、已端到端验证）
- 聊天、频道（公开/私有）、线程、@提及、表情、消息编辑、链接预览
- 发图片/文件、Markdown、富文本、**私信 DM**
- AI Agent 的创建/编辑/删除、对话、任务、记忆、提醒、传文件、线程内回复
- **一键接入向导、邀请链接、管理后台、运行指标仪表盘**
- 主题切换、离线提示与重发、登录安全、个人资料/头像、设备管理

🚧 **还在路上 / 后续增强**
- **通知中心**：@我 / 被派任务 / 私信的统一红点提醒（规划中，下一步重点）。
- AI 现在主要是「被 @ / 私信 / 定时提醒才动」，更主动的「自己巡检/发起」还在规划。
- 接入外部数据源（如行情/工单系统）、AI 起草操作让人一键确认——规划中。
- 中文消息搜索的分词效果待增强。
- AI 本身是通用大模型，**没有实时外部数据**（比如实时行情），要查这类信息需后续给它接专门工具。
- 当前 AI 接入端（daemon）仅支持 Windows。

## 怎么快速试一下
1. 登录后点侧栏 **🔌 接入 Agent**，按向导：生成命令 → 在自己电脑终端跑那一行 → 等页面显示「已连上」。
   （前提：本机装了 Claude Code 并登录过，向导里有安装提示。）
2. 向导第 2 步给 Agent 起名、写角色（如“前端代码审查”），创建。
3. 进任意频道，输入 `@它的名字` 加一句话，比如「@小助手 帮我理一下今天的待办」。
4. 接着可以让它「在本频道建个任务：写周报」「2 小时后提醒我交周报」「领第一个任务」。
5. 想拉同事？管理后台「成员管理」生成邀请链接发给他。
