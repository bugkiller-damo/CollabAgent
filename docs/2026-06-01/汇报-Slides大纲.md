# CollabAgent · 汇报 Slides 大纲

> 10–12 页，配合现场 Demo。每页给「标题 + 要点 + 讲什么」。建议总时长 15 分钟（讲 8 分钟 + Demo 5 分钟 + 问答）。

---

### 封面
- **CollabAgent —— AI 原生的团队协作平台**
- 副标题：人和 AI Agent 在同一套频道里协作 · 2026-06-01 进展汇报

### P1 · 一句话定位
- 像 Slack，但 **AI Agent 是一等团队成员**，不是外挂的问答机器人。
- 讲：先让大家脑子里有个锚——"团队聊天工具 + 能干活的 AI 同事"。

### P2 · 为什么做 / 解决什么问题
- 现有协作工具里 AI 只是"侧边栏问答"；我们要的是 AI **进到协作流里**——能被 @、领任务、记住事、主动跟进。
- 讲：价值主张，而非功能。

### P3 · 差异化（4 个关键词）
- 本机 daemon 驱动自己的 AI / 持久记忆 / 自主收发 / 一行命令接入。
- 讲：这几点把我们和"接个 ChatGPT API"区分开。

### P4 · 整体能力地图（一张图）
- 协作核心：消息·频道·线程·任务·提醒·附件·私信。
- Agent 运行时：daemon · 持久 Claude · 记忆 · 自主 CLI。
- 平台：组织/成员 · 实时推送 · 安全 · 可观测性。
- 讲：一眼看全盘，标注哪些"已完成 / 进行中"。

### P5 · 进度总览（红黄绿表）
- 用 `完成记录.md` 的状态对照表：核心闭环 ✅；本周新增 ✅；通知/自主/集成 🚧。
- 讲：诚实呈现完成度，绿的多、黄的有规划。

### P6 · 本周亮点（4 个图标卡）
- 🔌 一键接入向导 / 👥 邀请链接 + 管理后台 / 📊 运行指标仪表盘 / 🛠️ 底层修复与技术债清理。
- 讲：这是"上次到这次"的增量，体现持续推进。

### P7 · 【现场 Demo】（切到实机）
- 接入 → @Agent 建任务/改状态 → 邀请链接 → 指标盘。
- 讲：见 `汇报-Demo脚本.md`。这一段是全场重点，留足时间。

### P8 · 架构简述（给技术同事，1 页够）
- 浏览器/Agent ↔ 服务端（HTTP + WS）↔ 本机 daemon ↔ 本机 Claude。
- 技术栈：Fastify + PostgreSQL / React + Vite / 本机 Claude（持久进程）。
- 讲：非技术领导可快速带过。

### P9 · 工程质量
- 自动化测试 + CI（typecheck → migrate → 起服务 → 跑测试）、结构化日志、`/api/metrics` 可观测。
- 讲：不只是 Demo 能跑，是"敢改、可回归"的工程状态。

### P10 · 路线图（按优先级）
- **下一步 P1**：通知中心 · 中文搜索分词 · 安全硬化。
- **进阶**：Agent 自主巡检 · 第三方系统集成。
- **已知约束**：无实时外部数据需接工具 · daemon 仅 Windows · 容器化暂缓。
- 讲：让领导看到清晰的下一步和取舍。

### P11 · 结语 / 诉求
- 一句话总结 + 你需要的支持（人力 / 试用反馈 / 资源 / 接入哪个真实场景）。
- 讲：汇报要有"要什么"，别只是"做了什么"。
