# CollabAgent · 现场 Demo 脚本

> 目标：5–8 分钟，让观众看到「AI 同事接入有多简单 + 真能干活 + 系统可观测」。
> 原则：**少讲架构，多让屏幕说话**。每步先做动作，再说一句话。

## 演示前检查清单（务必彩排一遍）
- [ ] 后端 server 在跑（`http://localhost:3001/api/health` 返回 ok）
- [ ] 前端 web 在跑（`http://localhost:5173` 能打开）
- [ ] 本机已安装并登录 Claude Code（`claude --version` 有输出）
- [ ] 准备好一个干净的演示账号；浏览器缩放调大，字够大
- [ ] 终端窗口和浏览器并排摆好，方便来回切
- [ ] 网络正常（接入向导和 Agent 回复都依赖它）

---

## 主线（约 5 分钟）

### ① 接入：注册 → 一行命令连上本机 AI（约 90 秒）
**动作**：登录后点侧栏「🔌 接入 Agent」→ 第 1 步「生成接入令牌」→ 复制命令 → 贴到终端回车。
**等几秒，页面自动变「✅ 本机 Claude 已连上」。**
**话术**：「新同事入职，注册完只要复制这一行命令，几秒钟就把他自己电脑上的 AI 接进了平台——不用配置、不用部署。」

### ② 创建 Agent（约 30 秒）
**动作**：向导第 2 步，给 Agent 起名（如 `小助手`）、填角色描述（如"帮忙整理待办、写周报"）→ 创建。页面提示 Agent 上线。
**话术**：「这就是他的 AI 同事，有名字、有职责。」

### ③ 协作：@ 它，它自主回复 + 干活（约 2 分钟，**全场高潮**）
**动作**：进 `#general`，发「@小助手 帮我把今天讨论的三件事建成任务」。等它回复。
然后打开「任务看板」，能看到它**真的建了任务**。再发「@小助手 把第一个任务领了，状态改成进行中」。
**话术**：「注意——它不是回一句话就完了。它**读懂上下文、自己调工具建任务、改状态**。这就是『AI 是团队成员，不是问答机器人』的意思。它还有持久记忆，下次不用从头说。」

### ④ 多人协作：邀请链接（约 45 秒）
**动作**：「🛠️ 管理后台」→「成员管理」→「生成邀请链接」→ 复制。
**话术**：「拉同事进来就这一条链接，他点开注册就自动进了我们的协作空间，还能分配角色。」

### ⑤ 可观测：运行指标仪表盘（约 45 秒，**视觉收尾**）
**动作**：「管理后台」→「运行指标」。展示在线 daemon（带主机名、连接时长）、消息走势图、内存条。
**话术**：「系统是不是活的、几台机器在线、负载多少，一眼就能看到——运维和可观测性也跟上了。」

## 加分问答预案
- **Q：AI 回复要多久？** 首次稍慢、之后较快（进程保温）。是真模型在本地推理，不是预设话术。
- **Q：数据安全吗？** Agent 跑在用户自己机器上、用自己的 AI；平台侧有 JWT + httpOnly Cookie + CSRF + 登录限流；私有频道严格按成员投递。
- **Q：能接我们的工单/数据系统吗？** 架构已留第三方集成位，目前是规划项，可按需排期（出站 Webhook 最快落地）。
- **Q：能问实时行情/最新数据吗？** 通用大模型本身没有实时数据，需要后续给它接专门工具——这是已知约束，不是 bug。
- **Q：支持 Mac/Linux 吗？** daemon 当前仅 Windows，跨平台已评估、暂缓。

## 翻车预案
- **Agent 不回复**：先看终端 daemon 日志有没有报错；确认 `claude --version` 能跑、已登录。实在不行，切到「这里本该看到它回复」的话术，继续往下演，别卡死。
- **daemon 连不上**：确认命令里 `--server-url` 对、令牌完整；指标盘「在线 daemon」是最快的连通性判断。
- **兜底**：准备一份提前录好的 30 秒 Demo 录屏，现场环境出问题时直接放。
