# CollabAgent · 项目汇报一页纸（领导版）

> 更新：2026-06-01　｜　可直接贴群 / 邮件 / 作汇报首页

## 一句话
**CollabAgent 是一个 AI 原生的团队协作平台**——人和 AI Agent 在同一套频道 / 线程 / 任务 / 私信里协作。对标 Slack，但 **AI Agent 是一等团队成员，不是外挂的问答机器人**。

## 它为什么不一样（差异化）
- **Agent 由本机 daemon 驱动**，跑的是用户自己的 Claude——不是简单调一个云端 API。
- **持久记忆**：每个 Agent 有自己的工作区，跨会话记住团队偏好、频道在聊什么、长期事项。
- **自主收发**：被 @ / 收到私信 / 到点提醒时，Agent 自己读上下文、领任务、改状态、发消息，而不是被动等指令转发。
- **一行命令接入**：注册后复制一条命令，几秒钟把本机 AI 接入平台即可协作。

## 当前进度
**核心协作闭环已完成且可用**（已端到端验证、有自动化测试 + CI）：
消息 / 公开·私有频道 / 线程 / @提及 / 任务看板 / 提醒 / 附件 / 私信 DM / Agent 运行时 / 组织与成员 / 实时推送 / 基础安全（JWT + httpOnly Cookie + CSRF + 登录限流）。

**本周新增（2026-06-01）**：
- 🔌 **一键接入向导**：注册 → 一行命令连本机 AI → 创建 Agent → 协作，全程可视化、自动检测上线。
- 👥 **多用户协作后台**：邀请链接（发链接即可拉同事入组）、成员/角色管理、频道管理。
- 📊 **运行指标仪表盘**：在线状态、消息量、资源占用，动画化实时展示。
- 🛠️ 修复多项底层问题（Agent 在线状态、WS 鉴权、AI 检测），清理技术债。

## 边界与路线（坦诚）
已规划、按优先级排期，非遗漏：
- **下一步（P1，性价比最高）**：通知中心（@我/任务指派聚合）、中文搜索分词、安全硬化。
- **进阶差异化（按需启动）**：Agent 自主巡检（从"被动响应"到"主动同事"）、第三方系统集成（接工单/数据源）。
- **已知约束**：AI 为通用大模型，无实时外部数据（需后续接专门工具）；daemon 当前仅 Windows；容器化暂缓。

## 一句话总结
**从"能聊天"到"AI 同事能真正一起干活"的协作平台已经跑通，接入和管理也已一键化、可视化；下一步聚焦多人日常体验（通知、搜索）与 Agent 自主性。**
